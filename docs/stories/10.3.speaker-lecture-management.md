# Story 10.3 — Gestao de Palestra — Solicitacoes & Uploads

**Epic:** 10 — Painel do Palestrante — Dashboard de Leads & Gestao
**Status:** Ready for Review
**Points:** 5
**Priority:** P0 (Must)
**Executor:** @dev
**Quality Gate:** @qa

---

## Story

Como **palestrante**, quero poder gerenciar minha palestra pelo painel — solicitando mudanca de titulo, enviando arquivos complementares (slides, bibliografia) e visualizando o status das minhas solicitacoes — para que eu tenha autonomia sobre o conteudo da minha apresentacao sem depender do organizador para cada ajuste.

---

## Descricao

Adicionar a area "Minhas Palestras" no portal do speaker, onde cada palestra tem uma pagina de detalhes com: informacoes atuais, formulario de solicitacao de mudanca de titulo/descricao, upload de arquivos complementares, e historico de solicitacoes. O organizador recebe as solicitacoes no dashboard admin e pode aprovar/rejeitar.

---

## Technical Notes

### Storage Bucket
```
Bucket: speaker-uploads
Max size: 100MB
Allowed MIME types: application/pdf, application/vnd.ms-powerpoint,
  application/vnd.openxmlformats-officedocument.presentationml.presentation,
  application/msword, application/vnd.openxmlformats-officedocument.wordprocessingml.document,
  application/vnd.ms-excel, application/vnd.openxmlformats-officedocument.spreadsheetml.sheet,
  image/jpeg, image/png, application/zip
```

### Validacao Client-Side
- File size check antes do upload (< 100MB)
- File type check pela extensao e MIME type
- Contagem de arquivos existentes (< 10) antes de permitir novo upload

### Design System
- Usar shadcn/ui: Tabs, Card, Badge, Input, Textarea, Select, Button, Dialog (confirmacao), Progress
- Upload: usar componente de drag-and-drop ou Input type="file" estilizado
- Status badges: mesma paleta de cores do design system (green/yellow/red)
- Diff visual: `<del>` com bg-red-100 e `<ins>` com bg-green-100 para comparacao
